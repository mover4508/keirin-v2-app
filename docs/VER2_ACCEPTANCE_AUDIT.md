# Ver.2 全体監査・受入基準（2026-11-21）

## 固定仕様
- 3連複、1点100円、1レース1〜3点、レース見送りなし、5〜9車。
- スマートフォンで入力・予想・結果照合・バックアップ・復元まで完結。
- 出走表とオッズはチャリロト、公式結果はKEIRIN.JPの貼付を基本とする。
- 36エンジン（12系列×3レース区分）。区分は堅め・標準・荒れ。グレード・車立を考慮。
- 各買い目に勝因・敗因を記録。既存端末データの保護を最優先。

## 継続改善のループ
1. 改善候補を生成し、目的・影響範囲・検証基準を記録。
2. 過去に確定済みのデータで学習し、未使用の時系列データで比較。
3. 的中率と回収率を両方評価し、サンプル不足なら採用を保留。
4. データのバックアップと変更履歴を確保してから適用。
5. 適用後の新規レースで再評価し、悪化や不具合があれば復元。
6. 次の改善候補へ進む。無制限とは反復回数の上限を固定しない意味であり、1回ごとの計算量・権限・停止条件は必須。

## 完了判定
コード変更だけでは完成としない。自動テスト成功、Android実機の一連の操作、公式結果での照合、保存済み全レースの整合性、Google Driveへの全データバックアップと復元の実証が揃って初めて完了判定する。
