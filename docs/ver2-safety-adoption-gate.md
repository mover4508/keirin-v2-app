# Ver.2 安全な開発・採用ゲート

この文書は開発用ブランチ上の変更であり、公開アプリや保存済み70レースには影響しません。

## 不変条件
- 3連複、1点100円、1レース1〜3点、レース見送りなし
- 車立は5〜9車、ラインの読み取りを優先
- 予想時点で入手できない結果・払戻情報を予想入力に混入させない
- 結果照合後は各買い目について勝因・敗因の両方を保存
- データ更新前にバックアップと復元検証を行う

## 監査済みの課題
- 保存済み70レースの的中は21件、回収率は約59.7%（過去記録の集計であり前向き成績ではない）
- 区分は堅め39、標準31、荒れ0。閾値を恣意的に変更せず、払戻・ライン・オッズ取得率と併せて検証する
- 5車・8車など一部の条件に十分なサンプルがない。条件別モデルは十分な件数が揃うまで共通モデルへ縮約する
- 36エンジンの実装と、各エンジンの予測改善効果の実証は別物

## 変更採用プロセス
1. 改善案と変更する変数を記録する
2. 時系列分割した独立データで旧方式と比較する
3. 的中率、回収率、買い目変更数、条件別成績、欠損率を評価する
4. 前向きデータで再検証し、過学習の疑いがあれば保留する
5. 復元可能なバックアップを確認してから本番へ反映する
6. 反映後も監視し、悪化したら以前の版へ戻す

「無制限メタループ」は改善サイクルの反復回数に上限を設けない設計方針であり、個々の処理にはタイムアウト、反復回数、メモリ・通信上限、停止条件を設ける。

## 本番反映前の必須確認
- HTML/JavaScript構文検査
- 3連複組番と点数・金額の境界値テスト
- 締切前/事後データの隔離テスト
- 36エンジンとレース区分の再現性テスト
- Google Drive保存・復元・通信失敗テスト
- Android実機操作テスト

この文書の追加だけでは上記機能の実装完了を意味しない。
